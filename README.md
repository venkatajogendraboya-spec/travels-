# TEJOE TRAVELS — HTML, CSS & JavaScript Starter

## Files
- `index.html` — website structure and sections
- `style.css` — responsive styling
- `script.js` — destination cards, filters, sample package details, search, trip estimate and demo forms

## Run locally
1. Extract `tejoe_travels_html_css_js.zip`.
2. Open the extracted `index.html` in Chrome, Safari, Firefox or Edge.
3. For a local development server, open the folder in VS Code and use the Live Server extension.

## Important notes
This is a front-end starter built with plain HTML, CSS and JavaScript. It includes working client-side interactions and sample travel content. It does **not** include a real backend, database, user authentication, admin dashboard, live availability, email delivery, maps API or payment processing. The newsletter and trip planner currently show demo responses only. No real bookings or payments are made.

Destination photos are loaded from Unsplash URLs and Google Fonts are loaded online, so an internet connection is needed for those assets. Replace sample prices and content with verified business information before publishing.

## Suggested next step for a real booking platform
Connect a backend (for example Supabase) for accounts, packages, bookings and admin roles. Keep payment secrets on the server and use a payment provider's test mode with server-side payment verification. Do not store passwords or payment details in browser JavaScript.
